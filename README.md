# Ravnsight Detective – Error & Change Monitoring

The free WordPress plugin: PHP errors grouped and attributed to the plugin
that caused them, plus a timeline of every plugin, theme and core change.
Fully local — it never sends anything anywhere.

- Website: https://ravnsight.com/plugins/ravnsight-detective
- Support: https://ravnsight.com/support

This repository mirrors the released free build. Development happens in a
private monorepo; issues and PRs are handled via the support channels above.
